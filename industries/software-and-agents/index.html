Rules already in place

Teams relying on coding tools and agents can already ask for the evidence

These are the rules and standards a buyer of AI coding tools or agents can point to when it asks the vendor for evidence.

  1. Federal AI purchases. OMB Memorandum M-25-22 tells agencies to test AI where practicable and to use their own data when they run independent evaluations.
  2. Federal software security. OMB Memorandum M-26-05 (January 2026) has agencies check software providers' security with a risk-based approach. It rescinded the earlier attestation memos M-22-18 and M-23-16.
  3. FedRAMP. Under FedRAMP 20x, cloud providers get independent assessment on a set schedule: initial certification under the new rules from July 4, 2026, and ongoing certification from January 1, 2027.
  1. California state contracts. State IT and telecom solicitations and contracts must include language requiring the contractor to notify the state of generative AI use.
  2. A shared standard to start from. NIST SP 800-218A gives a buyer and a producer a common set of secure development practices for generative AI to agree on. It is voluntary.
Where it fits

Where an outside check fits work you already do

  1. Before it gets access. Before a tool or agent gets repository access or customer data, make the vendor's evidence for each claim a required submittal and have it examined. See the sample requirement.
  2. In your environment. Have someone test whether the stated limits, review steps and quality checks actually work on your code and your permissions.
  3. In a deal. If you're investing in or buying a company built on agents, the check can be a condition of closing. For investors and acquirers.

A pilot is $9,000, fixed, for a first look at one AI product.

The claim

"Our coding agent's changes pass your test suite 90% of the time."

Finding 1, how far the evidence reaches: Shown to be flawed. The vendor ran the agent on public repositories and counted runs where the agent had edited the tests themselves.

Finding 2, sound evidence the claim is false: Yes. Counting only runs where the tests were left unchanged, the vendor's own results fall well below 90%.

Before you rely on an AI claim

You can require an outside check

If your decision rests on what a vendor says its AI product does, you can make an outside check of that claim a condition of the purchase, the policy or the deal. The report comes only to you.
